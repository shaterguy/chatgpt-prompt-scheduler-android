# ChatGPT Prompt Scheduler for Android

ChatGPT 웹 세션에 예약 프롬프트를 자동 전송하는 독립 Android 앱입니다. Chrome 확장프로그램이나 외부 브라우저에 의존하지 않습니다.

개발 채널 `v0.3.0-dev4`에서는 예약 실행 기능만 유지하며 오토런 중계 기능은 제거했습니다. 프로젝트 예약은 프로젝트 URL을 직접 입력하지 않고, 메인 화면의 `로그인/세션` WebView에서 사용자가 ChatGPT 프로젝트를 직접 열면 앱이 해당 프로젝트 주소와 표시명을 로컬 프로젝트 목록에 등록하는 방식으로 동작합니다.

- DEV versionName: `0.3.0-dev4`
- DEV versionCode: `3000004`
- DEV Application ID: `com.shaterguy.chatgptpromptscheduler.dev`
- Android 8.0 이상

## 주요 기능

- 일반 Chat, 프로젝트 새 대화, 기존 대화 예약
- Chat·Work 모드와 Work 모델·추론 설정
- 일회성·매일·매주·분 간격 반복
- 기존 입력 교체와 전송 결과 검증
- 설정 JSON 내보내기·가져오기
- 실행 기록과 실패 로그 내보내기
- 로그인/세션 WebView에서 방문한 프로젝트 자동 등록

## 프로젝트 예약 등록

1. 메인 화면에서 `로그인/세션`을 엽니다.
2. ChatGPT에 로그인한 상태에서 예약에 사용할 프로젝트를 직접 엽니다.
3. 앱은 현재 페이지가 `https://chatgpt.com/g/g-p-...` 형식의 정상 프로젝트인지 검증한 뒤 canonical 프로젝트 주소와 화면에서 확인한 프로젝트명을 로컬에 저장합니다.
4. 예약 편집에서 대상 유형을 `project`로 선택하면 등록된 프로젝트 목록에서 선택할 수 있습니다.
5. 기존 버전에서 직접 저장한 정상 프로젝트 URL 예약은 앱이 프로젝트 목록으로 자동 이관합니다.

프로젝트 목록에는 쿠키, 세션 토큰, 페이지 HTML이나 대화 내용이 저장되지 않습니다. 기존 대화(`existing`) 예약은 대화 URL을 직접 지정하는 현재 방식을 유지합니다.

## 정식 업데이트 계보

정식 앱과 DEV 앱은 별도 Application ID로 동시 설치할 수 있으며, 정식 릴리스에서는 기존 정식 앱의 Application ID와 서명 계보를 유지해야 합니다. DEV 산출물은 정식 앱을 대체하지 않습니다.
